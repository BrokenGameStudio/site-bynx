Codes de retour de l'installateur EXE

Référence des scénarios d'installation et des codes de retour utilisés pour la distribution du launcher BrokenGame Studio via le Microsoft Store.

Projet : BrokenGame Studio Plateforme : Windows 10 / Windows 11 Distribution : Microsoft Store — Partner Center Format : EXE (Win32)
À lire avant configuration Les codes personnalisés proposés dans cette documentation constituent une convention pour l'installateur. Ils ne sont pas imposés par Microsoft. L'installateur doit réellement renvoyer le code configuré dans Partner Center. Certains codes standards Windows peuvent être réutilisés si leur signification correspond exactement au scénario.

2. Description des scénarios

0Succès

Installation réussie

L'installation s'est terminée correctement. L'application peut être lancée normalement.

Action : aucune intervention nécessaire.
100Information

Application déjà installée

Une installation existante a été détectée sur l'appareil.

Action : vérifier si une mise à jour est disponible et éviter une seconde installation inutile.
101En attente

Installation déjà en cours

Une autre opération d'installation est déjà active.

Action : attendre sa fin avant de relancer l'installation.
102Erreur

Espace disque insuffisant

L'appareil ne dispose pas de suffisamment d'espace libre pour installer l'application.

Action : libérer de l'espace disque puis réessayer.
103Redémarrage

Redémarrage requis

Un redémarrage de Windows est nécessaire pour finaliser l'installation.

Action : informer l'utilisateur et lui demander de redémarrer l'appareil.
104Erreur

Échec réseau général

Une erreur réseau a empêché le téléchargement ou la récupération des ressources nécessaires.

Action : vérifier la connexion Internet puis réessayer.
105Sécurité

Package rejeté

Windows a bloqué l'installation en raison d'une stratégie de sécurité appliquée sur l'appareil.

Action : vérifier les stratégies de sécurité. Ne pas tenter de contourner les protections du système.
106Annulation

Installation annulée

L'utilisateur a volontairement annulé l'opération.

Action : arrêter proprement l'installation. Ne pas présenter l'annulation comme une panne technique.

4. Recommandations d'implémentation

  • Chaque code doit correspondre à un seul scénario clairement identifié.
  • Le code 0 doit indiquer une installation réussie.
  • Les codes personnalisés doivent être déclarés dans Partner Center et renvoyés par le programme d'installation.
  • Ne pas renvoyer un code de succès si l'installation a échoué ou a été seulement partiellement effectuée.
  • Enregistrer les détails techniques dans les journaux d'installation, sans y inclure de données personnelles inutiles.
  • Vérifier le comportement réel des codes avec chaque version de l'installateur.
  • Ne pas confondre un code de retour de l'installateur avec un code d'erreur interne au launcher.
